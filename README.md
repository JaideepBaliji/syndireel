# SyndiReel

A cinematic community website with an animated logo, scroll-driven 3D scenes, upcoming screening details, and a gallery of community photographs and merchandise.

## Stack
HTML5, custom CSS, vanilla JavaScript. No build step or dependencies.

## Preview locally
Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Deploy on Vercel
Import this repository, select Other as the framework, leave the build command empty, and use the repository root as the output directory.

## Pages
- `index.html`: homepage and gallery preview
- `gallery.html`: Community and Merch gallery sections with an accessible image viewer
